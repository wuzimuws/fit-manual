# 1. 心态

这一节排在最前面，因为它决定后面 5 节你能不能读下去。

我不谈天赋，不谈毅力，也不打算在第 3 条之后就劝你「坚持」。这本书只回答一件事：**你这个身体，接下来几周该做什么。**

---

## 主题一 · 为什么开始

> **作者主张**：年纪上来、肚子起来、暴饮暴食、皮肤变差——我是被身体逼来的。目标不是「变健康」这种空话，是变健康、有好身材、**取悦自己**。

---

### 1. 别拿「变健康」当唯一理由，它撑不过三个月

- **我当时**：〔待你补〕
- **卡在哪**：给自己定的理由是「想变健康」。听着对，但健康没有刻度、没有反馈、也不疼——练了两周就找不到任何理由继续，因为看不见任何变化。
- **说人话**：拿「健康」当唯一理由的人，大多会停。「想好看」和「想取悦自己」这两条才撑得住，因为它们有镜子、有照片、有即时反馈。
- **怎么做**：把你的理由写下来，划掉所有「应该」开头的，只留「我想要」开头的。留下的如果不够两条，说明你还没准备好开始，先别办卡。
- **什么时候改**：三个月后如果「想好看」这条已经不给力了，就换「取悦自己」顶上——它不是备胎，它是最耐用的那条。
- **别做**：别把动机押在健康指标上（体检报告、体脂秤）。它们半年才动一次，不动的时候你无处可依。
- **算账**：代价 时间 5 分钟写理由 → 换回 一条能撑一年的动机
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 2. 肚子先大是结果，不是原因——先管腰围，别管体重

- **我当时**：〔待你补〕
- **卡在哪**：体重秤涨了两斤就慌，饿两天又掉回去。来回折腾一年，肚子一点没小。
- **说人话**：内脏脂肪比皮下脂肪先堆、也先掉。所以第一年里，**腰围比体重更能说明问题**——体重里有水分，腰围没有。
- **怎么做**：每周固定一次，早上、空腹、排便后，皮尺绕肚脐水平一圈，记进训记。三个月腰围降 3–5 cm 就是明显进展，这期间体重可能一点没动。
- **什么时候改**：连续四周腰围一动不动，先查两件事——晚上是不是吃太晚、是不是只做有氧没做力量。别急着加练。
- **别做**：别买体脂秤，别每天称体重。一天之内的体重波动能有 1–2 kg，全是水。
- **算账**：代价 时间 1 分钟／周 → 换回 一个不会被水分骗到的指标
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 3. 暴饮暴食不是意志力问题，是吃饭时间的问题

- **我当时**：〔待你补〕
- **卡在哪**：白天几乎不吃，晚上报复性吃一堆，吃完骂自己没自制力；第二天更不吃，晚上吃更多。这个循环我走了很久。
- **说人话**：多数暴食不是「管不住嘴」，是**白天欠的账晚上一次性还**。你骂自己没用，改吃饭时间才有用。
- **怎么做**：固定三餐，最要紧的是别省早餐和午饭；每餐先吃蛋白质（鸡蛋、肉、豆制品），再吃主食。**饿到极点才吃的那一顿一定会过量**，这跟意志力无关。
- **什么时候改**：三餐规律了还是压不住，再看是不是整体吃得太少——长期缺口太大，身体会反过来逼你暴食。
- **别做**：别用「这周断食补回来」解决暴食。断食→暴食→再断食，是把循环拧得更紧的那只手。
- **算账**：代价 毅力中（前两周要逼自己吃早饭） → 换回 断掉「暴食—自责」的死循环
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 4. 皮肤变差这件事，训练能帮的比你想的少

- **我当时**：〔待你补〕
- **卡在哪**：把「皮肤变好」算进了健身收益，练了没变化就很失望，甚至觉得白练了。
- **说人话**：练完皮肤看着好，多半不是训练的功劳，是顺带的——出汗洗脸、晚上睡得沉一点、压力小一点。**别把皮肤当健身的 KPI**，它会让你误判进展。
- **怎么做**：把皮肤从你的训练收益清单里划掉。真想它变好，直接去管睡眠和洗脸，那两件比训练管用，也更省时间。
- **什么时候改**：如果皮肤是你开始健身的**唯一**理由，说实话，去挂皮肤科比办卡快。
- **别做**：别买「健身排毒」类护肤品和补剂。出汗不排毒，汗就是水和盐。
- **算账**：代价 0（只是别指望） → 换回 不因为一个错误指标而放弃
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 5. 「取悦自己」是唯一不需要别人打分的动机

- **我当时**：〔待你补〕
- **卡在哪**：刚开始练总怕被看、怕练得轻被人笑。注意力全在别人身上，一次练完比没练还累。
- **说人话**：健身房里绝大部分人根本不会看你，剩下看两眼的也在想自己的事。练一年你会发现，**你身上唯一稳定可靠的观众是你自己**。
- **怎么做**：把评价权拿回来。练完那一刻你自己舒不舒服，是唯一有效的评判。别人看不看，跟你明天去不去练没有关系。
- **什么时候改**：哪天你发现自己是为了发朋友圈、发抖音才去练的，那天就停下来问一句：不给我点赞，我还去不去？
- **别做**：别跟人比重量（别人杠铃片数跟你的进步毫无关系），别把训练成果当成给人看的作品。
- **算账**：代价 0 → 换回 一个不会因为没人点赞就消失的动机
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕
