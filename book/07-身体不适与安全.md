# 7. 身体不适与安全

这一节是全书唯一一节 **「先查、再练」** 的地方。

前面六节都建立在「你是个能正常训练的人」这个前提上。这一节处理的是：**如果这个前提不成立呢？** 有些问题不该靠熬、靠调整动作来解决，该去医院。

**先花一次抽血的钱，把不确定的那部分问清楚——这比任何补剂都值。**

### 1. 先查一次维生素 D，再开始练

- **我当时**：〔待你补〕
- **卡在哪**：刚开始练的时候只想着"怎么练"，从来没想过"我能不能练"。直到出了问题才去查血，发现维生素 D 一直偏低。
- **说人话**：**这是全书唯一一条「先查再练」的前置动作。** 尤其是久坐办公的人——**负重刺激少，是低骨密度的高风险人群**。
- **怎么做**：去**内分泌科**，抽血查 **25-羟基维生素 D**。就这一项，一次抽血。
- **什么时候改**：查出来低就按医生给的剂量补（见 05 节），三到六个月复查一次；正常就不用长期吃。
- **别做**：别靠"我晒了太阳应该不缺"来判断。**这件事不用猜，抽个血就知道——这本来就是"唯物主义"该有的样子。**
- **算账**：代价 一次抽血的钱和时间 → 换回 不拿骨折风险赌
- **我练下来**：〔待你补〕

### 2. 维生素 D 低了会怎样：两件事

- **我当时**：〔待你补〕
- **卡在哪**：以为维 D 只是"骨头的事"，跟自己练铁没关系。
- **说人话**：维 D 低会同时影响**两个方向**——**骨密度**（骨头变脆）和**耳石症的复发**。而训练是给骨头加负荷的事，**骨头脆的时候加负荷，就是骨裂和骨折的时机。**
- **怎么做**：把这条和 05 节的补剂条、下面第 4 条的耳石症条当成**一件事**来看：
  > **查一次维 D → 低了就补 → 既防耳石症复发，也防训练中骨折。**
- **什么时候改**：复查之后没上来，剂量交给医生调，别自己加。
- **别做**：别在明知道维 D 低的情况下继续冲大重量。**这是唯一一条"先别练"的红线。**
- **算账**：代价 几百元的检查加补剂 → 换回 不用在骨折之后才回头查
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 3. 训练时不要过度憋气

- **我当时**：〔待你补〕
- **卡在哪**：刚开始练推类动作习惯憋气发力——因为憋着气确实能推得更重一点，还觉得自己"找到核心了"。
- **说人话**：**过度憋气要停。** 憋气（大重量时屏住呼吸）会**升高胸腔和颅内的压力**，可能带来眼前发黑、头晕、血压骤变。**对已经有耳石症的人，还可能直接诱发眩晕。**
- **怎么做**：
  - **发力时呼气，还原时吸气**——这是默认做法
  - 大重量、要稳定核心的那一两下**可以短憋**，但憋完立刻呼气，**不要连续多组憋**
  - 任何时候出现**头晕、眼前发黑、耳鸣**，立刻停下,把重量放下
- **什么时候改**：开始有头晕就当天停止，不要"再试一组看看"。
- **别做**：别把憋气当成"核心力量的证明"。**它证明的不是力量，是你把血压顶上去了。**
- **算账**：代价 每次少推一点点重量 → 换回 不用拿头晕换那一点重量
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 4. 我的个案：维 D 偏低 + 习惯憋气，后来得了耳石症

> **这一条是作者本人的经历，不是普遍规律。** 别把"憋气的人都会得耳石症"读进去。

- **我当时**：〔待你补——什么时候开始头晕、什么时候确诊、那段时间在练什么〕
- **卡在哪**：刚开始训练时习惯憋气，同时维生素 D 一直偏低。后来出现了眩晕，确诊为**耳石症**。
- **说人话**：我的情况是**两件事叠在一起**——一个是医学上已知的相关因素（维 D 低），一个是我自己的推测（憋气）。**两半的可信度不一样，我分开说：**
  - **维生素 D 偏低**：这块是有共识的——BPPV（耳石症）与血清 25-羟基维生素 D 偏低相关，补维 D 能降低复发。**这条你可以直接照做。**
  - **训练时习惯憋气**：**我怀疑跟它有关**，因为憋气会升高颅内压。但"憋气导致耳石症"**不是我查到的医学共识**，只是我自己的判断。**你可以参考，但别当结论。**
- **怎么做**：如果你也在练憋气、也开始头晕——**先去医院，再回来看这一节。**
- **什么时候改**：确诊之后怎么练，看下一条。
- **别做**：别照抄我的因果链去吓自己或吓别人。**主张可以是我的，事实不能。**
- **算账**：代价 — → 换回 一条别人不会告诉你的前置检查
- **我练下来**：〔待你补〕

### 5. 确诊之后，我避开哪些动作、怎么替代

- **我当时**：〔待你补——确诊后休了多久、第一次回来什么感觉〕
- **卡在哪**：确诊之后不知道还能不能练。查不到"耳石症患者的训练方案"，网上全是休息和复位，没人说训练怎么办。
- **说人话**：耳石症之后我没停练，但把训练**整体换了个方向**——**避开所有需要憋气的推类动作，把重心移到背、二头和后束**。腿每周练 1 次。
- **怎么做**：
  - **避开**：卧推、站姿推举这类一憋气就把压力顶上去的推类动作；任何会让你头晕的体位变化（快速低头、仰头、翻身类动作）
  - **替代**：固定器械（轨迹固定、能正常呼吸完成）、坐姿类动作、以及**背 / 二头 / 后束**为主
  - **保留**：腿，但每周只排 1 次
  - **呼吸**：每一组都按"发力呼气"走，不憋
- **什么时候改**：任何一次训练出现眩晕，立刻停，别硬撐完这一组。
- **别做**：别把"避开"理解成"再也不能练"。**我换的是方向，不是停止。**
- **算账**：代价 放弃一部分动作 → 换回 一年没再复发，训练也没断
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 6. 关节和肌肉不适，一定要重视

- **我当时**：〔待你补〕
- **卡在哪**：一开始的逻辑是"练开了就好"，把尖锐的疼也当成正常的酸。忍了两个月，最后停练。
- **说人话**：**遇到关节、肌肉不适一定要重视。** 不适的意义不是"要不要忍"，是**"身体在给你一个可以免费排查的报警"**。忽略它的代价，是后来花更多时间停练。
- **怎么做**：出现不适，按三步走——① 停掉引起它的那个动作，**其他部位照常练**（不用整个停）② 按下面两条把问题描述清楚 ③ 该去医院就去
- **什么时候改**：不适持续超过一周、或者有**尖锐痛、麻、关节响痛、肿胀**，直接去医院，别在网上自我诊断。
- **别做**：别用"再练练看会不会好"拖过一周。**一周是一个分水岭：一周以内的多半能自己过去，超过一周的基本不会自己好。**
- **算账**：代价 停一个动作一两天 → 换回 不用停一个月
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 7. 怎么把不适描述到「能被判断」

- **我当时**：〔待你补〕
- **卡在哪**：想找人问、想搜答案，但只会说"我肩膀疼"——这个描述任何人都给不出有用的回答，包括医生。
- **说人话**：**「哪里疼」说不清，是因为你在用日常语言描述一个解剖学位置。** 换一套说法，答案的质量立刻不一样。
- **怎么做**：描述四件事——
  1. **位置**：具体到哪块肌肉或哪个关节（"肩胛骨内侧缘、肩胛下角以上" 而不是 "后背疼"）
  2. **动作**：做什么动作时疼（"手臂抬到耳朵高度时" 而不是 "抬手疼"）
  3. **性质**：钝 / 尖锐 / 麻 / 酸胀 / 卡顿
  4. **时间**：当场就疼，还是第二天才疼；持续多久
- **什么时候改**：描述不清楚的时候，先别急着问——回去按第 8 条把位置定下来。
- **别做**：别拿"疼得厉害"当主要信息。**疼的程度最没用，"在哪、什么时候、什么性质"才有用。**
- **算账**：代价 时间 2 分钟组织语言 → 换回 一次问对，不用反复猜
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 8. 用解剖软件 + AI，把不适查清楚

- **我当时**：〔待你补〕
- **卡在哪**：去医院排队两周，自己想先搞明白是什么情况，又不知道从哪查起。
- **说人话**：**02 节那个解剖软件，在这里才是真正的用处。** 它不只是给你认肌肉的——**它让你能准确说出"是哪一块"和"是哪一条路的"。**
- **怎么做**：三步——
  1. **打开解剖软件**，按第 7 条的"位置 + 动作"找到具体是哪块肌肉、哪个关节、哪条运动轨迹
  2. **向 AI 描述症状**：把第 7 条那四件事说全，**并且说清是哪块肌肉/关节**（"肩胛骨内侧、菱形肌区域，手臂前伸时尖锐痛"）
  3. **让 AI 给出**：① 可能的原因 ② 该停哪些动作 ③ **哪些关联肌肉需要强化**（比如肩痛往往要练肩袖和前锯肌）
- **什么时候改**：AI 给的答案如果涉及"要不要就医""要不要吃消炎药"，一律以医生的为准。
- **别做**：**别把 AI 当医生。** 它的用处是帮你把问题**描述清楚、缩小范围**，不是下诊断。
- **算账**：代价 时间 10 分钟描述清楚 → 换回 一次问对；去医院时也能说清
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕
