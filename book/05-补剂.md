# 5. 补剂

这一节很短，因为答案是：**你只需要五个。**

先说一件事——这份名单里**没有一个是智商税**。市面上新手最常被推销的是 BCAA、氮泵、睾酮素、左旋肉碱、CLA，**这五个一个都不在里面**。你被推销的那些，绝大多数可以一分钱不花。

顺序上，**补剂永远排在最后**：先把吃够、睡够、练对做完了，再来看这五个。在那之前买补剂，都是拿钱买心理安慰。

---

### 1. 新手只需要五个补剂，其他都别买

- **我当时**：〔待你补〕
- **卡在哪**：看直播、看短视频，被推过一堆东西——BCAA、氮泵、睾酮素、左旋肉碱、CLA。名字都很厉害，说明书都很玄，价格都不便宜。
- **说人话**：值得买的就五个——**肌酸（一水）、咖啡因、甘氨酸镁、维生素 D、鱼油**。其他的，等你练满一年再回头讨论。
- **怎么做**：把预算全部压在这五个里。如果只能买一个，买**肌酸**。
- **什么时候改**：这五个都吃上了、饮食睡眠训练也都没问题，还是不见进展——那时候该改的是训练和饮食，**不是加第六个补剂**。
- **别做**：别买 BCAA（你只要吃够蛋白，它就没意义）、别买氮泵（本质是咖啡因＋香精，贵十倍）、别买睾酮素（口服的没用，有用的买不到）、别买左旋肉碱和 CLA（证据太弱）。
- **算账**：代价 钱 每月几十元（五个加起来） → 换回 省掉每月几百到上千的智商税
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 2. 肌酸：买一水肌酸就行，别买贵的

- **我当时**：〔待你补〕
- **卡在哪**：搜"肌酸"，出来的全是各种"高级形态"，价格差好几倍，完全不知道该买哪个。
- **说人话**：**买最便宜的「一水肌酸」就对了。** 所有花哨的形态（盐酸肌酸、乙酯肌酸等）贵好几倍，但没证明比一水更好。**这是整份名单里性价比最高的一项。**
- **怎么做**：每天 **3–5g**，什么时候吃都行，不用掐时机。**不用做「冲击期」**（那些"第一周六天每天 20g"的说法是过时的）。
- **什么时候改**：吃两三周后体重涨 1–2 kg 是正常的——**那是肌酸把水带进了肌肉，不是胖**，别慌着停。
- **别做**：别买「液体肌酸」「肌酸胶囊」这类贵形态。粉最便宜，一样用。
- **算账**：代价 钱 每月 20–40 元 → 换回 力量表现有提升，且是五样里证据最硬的
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 3. 咖啡因：从每天 100mg 起，记得把咖啡算进去

- **我当时**：〔待你补〕
- **卡在哪**：以为"喝咖啡提神"就算补剂了，结果晚上睡不着，白天又靠咖啡撑——循环起来了。
- **说人话**：咖啡因是有效的，但**它的第一个作用是偷你的睡眠**。所以新手先从**每天 100mg** 开始，**并且把这算进去**——一杯美式差不多就是 80–100mg，喝一杯基本就到位了。
- **怎么做**：每天总量控制在 **100mg 起**（含咖啡、茶、可乐、能量饮料里的）。**下午 3 点后不要再摄入**，否则当晚睡眠开始还账。适应两三周、睡眠没受影响，再按体重往上调（**3 mg/kg 起，70kg 约 200mg**）。
- **什么时候改**：入睡变慢、半夜醒、早上起不来——**任何一条出现，先把咖啡因降到 100mg 或停掉**。
- **别做**：别用咖啡因补觉，也别为了训练表现牺牲睡眠。**睡不够的话，咖啡因补不回你损失的东西。**
- **算账**：代价 每天几十元或一杯咖啡 → 换回 训练日多一点劲；代价是可能失去睡眠
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 4. 甘氨酸镁：晚上吃，为了睡

- **我当时**：〔待你补〕
- **卡在哪**：练完很累但睡不实，半夜醒，第二天还是没恢复。
- **说人话**：镁是**这五个里唯一主要为了「睡」而不是为了「练」的**。选**甘氨酸镁**（不是氧化镁——氧化镁吸收差，基本只能通便）。
- **怎么做**：睡前 30–60 分钟，**元素镁 200–400mg**。甘氨酸镁本身有助放松，放在睡前最合适。
- **什么时候改**：吃了之后白天犯困，就往睡前挪，或者减量。
- **别做**：别买"氧化镁"或"镁片"图便宜——**那类主要作用是通便，不是补镁。**
- **算账**：代价 钱 每月 30–60 元 → 换回 夜里睡实一点（正好接下一节）
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 5. 维生素 D：先查血，再决定吃不吃

- **我当时**：〔待你补〕
- **卡在哪**：听说"人人都缺维 D"，就直接买来吃，剂量全凭网上说的。
- **说人话**：维生素 D 是这五个里**唯一一个「先验再买」的**。缺不缺，抽个血就知道，不用猜。**这也是"唯物主义"最该有的样子。**
- **怎么做**：**先去内分泌科查一次「25-羟基维生素 D」**（怎么查、为什么查，见 07 身体不适与安全）。查出来低，按医生给的剂量补；正常就不用长期吃。
- **什么时候改**：补了三到六个月复查一次，看有没有上来。
- **别做**：别自己拍脑袋吃大剂量。**维 D 是脂溶性的，吃多了排不掉。**
- **算账**：代价 一次抽血 → 换回 不猜。低了补上，同时防两件事（见 07 节）
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 6. 鱼油：看有效成分，不看瓶子大小

- **我当时**：〔待你补〕
- **卡在哪**：买了瓶鱼油，吃了半年不知道有没有用——因为根本没看里面到底有多少 EPA 和 DHA。
- **说人话**：鱼油的关键不是"多少毫克鱼油"，是里面**EPA + DHA 加起来有多少克**。瓶子上的大数字通常不是这个数。
- **怎么做**：每天 **EPA + DHA 合计 1–2g**。买的时候直接翻到成分表，找这两个词，加一下。
- **什么时候改**：吃着没任何感觉是正常的——**这一项的作用是长期缓慢的，不是吃了就有感觉的**，别因为"没感觉"就不吃，也别指望它有感觉。
- **别做**：别看"鱼油 1000mg"就以为是 1000mg 有效成分——**那 1000mg 里可能只有 300mg 是 EPA+DHA。**
- **算账**：代价 钱 每月 40–80 元 → 换回 长期收益，见效最慢的一项
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕

### 7. 补剂排在最后：这三个没做到，买什么都白搭

- **我当时**：〔待你补〕
- **卡在哪**：一开始把希望押在补剂上，蛋白粉买最好的、肌酸买最贵的，但饭吃得不够、觉睡得不够。
- **说人话**：补剂的作用有多大，取决于它下面那三层垫得有多实。**顺序是：吃够 → 睡够 → 练对 → 才是补剂。** 上面一层没做，下面一层的钱全打水漂。
- **怎么做**：先回 04 节确认吃够了（四条判据都成立），再回 06 节确认睡眠，再回 03 节确认训练。**三样都过关，再来买这五个。**
- **什么时候改**：任何时候想买新补剂，先问一句：上面三样我做到了吗？
- **别做**：别用「反正便宜，买了先吃着」说服自己。**这句话是所有智商税的开头。**
- **算账**：代价 0 → 换回 花在补剂上的每一分钱都真的有用
- **我练下来**：〔待你补〕
- **来源**：〔待你补〕
