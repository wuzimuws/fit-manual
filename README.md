# 高性价比新手小白健身指南

给刚开始想健身的成年人：**不谈天赋，不谈毅力，只谈你这个身体接下来几周该做什么。**

作者练了一年，踩过坑，也看过一些书和视频。这本书把那些"我当初卡在哪、后来怎么过来的"摊开写下来。

---

## 立场声明

**这本书砍掉了这些话。** 你在这本书里找不到：

> 「因人而异」·「仅供参考」·「不是个人处方」·「可能有帮助」·「建议尝试」·「视情况而定」·「尚无定论」

因为这些话说了等于没说。新手要的不是免责声明，是**一个可以照着做的判断**。所以每一条都给具体的数字、具体的信号、具体的取舍——**错了是我的，你自己能验证。**

**这本书不承诺什么**：它不能替代教练、医生和康复师。它是"你该知道什么"的清单，不是"有人陪你练"的服务。

**这本书的资料来源**：作者读过的书 + 看过的抖音视频。**不是学术文献。** 所以每条的「主观证据等级」和「来源」由作者自己标——**把二手转述和一手验证分开**。这本书不装客观，主观的部分老实标出来。

## 每条长这样

```markdown
### <动词开头，或用新手的原话：一个真会撞上的问题>

- 总结性建议：<一句话给结论，敢下判断>
- 具体地：<数字、步骤、信号>
- 为什么这样建议：<机制，不讲玄学>
- 主观证据等级：<强 / 中 / 弱>
- 来源：<书 / 视频链接>
```

**主观证据等级**是这本书里唯一"主观"的东西，三档：

| 档 | 什么情况 |
|---|---|
| **强** | 有明确机制或有共识，且我自己验证过 |
| **中** | 常规做法、道理站得住，但主要靠经验 |
| **弱** | 只有我个人的体感，别人不一定适用 |

「来源」栏填的是**书或抖音视频的链接**，也就是"这话我从哪儿学来的"——不是"这话被哪篇论文证过"。这正是这本书叫「指南」的地方：**不装客观，把主观的部分老实标出来。**
