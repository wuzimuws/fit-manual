# 高性价比新手小白健身指南

给刚开始想健身的成年人：**不谈天赋，不谈毅力，只谈你这个身体接下来几周该做什么。**

作者练了一年，踩过坑，也看过一些书和视频。这本书把那些"我当初卡在哪、后来怎么过来的"摊开写下来。

它不能替代教练、医生和康复师。它是一份「我该知道什么」的清单，不是「有人陪你练」的服务。

## 每条长这样

```markdown
### <新手会问出来的那个问题>

- 总结性建议：<一句话给结论，敢下判断>
- 具体地：<数字、步骤、信号>
- 为什么这样建议：<机制，不讲玄学>
- 主观证据等级：<A / B / C>
- 来源：<书 / 视频链接>
```

**标题一律用疑问句**——是新手真会问出来的那个问题（「一组做几次？」「要不要戴手套？」）。
因为这本书的骨架就是问题接着答案：标题问，下面的「总结性建议」答。翻目录的时候，你是在找自己的问题，不是在读目录。

**主观证据等级**是这本书里唯一"主观"的东西，三档：

| 等级 | 什么情况 |
|---|---|
| **A** | 有明确机制或有共识，且我自己验证过 |
| **B** | 常规做法、道理站得住，但主要靠经验 |
| **C** | 只有我个人的体感，别人不一定适用 |

「来源」栏填的是**书或抖音视频的链接**，也就是"这话我从哪儿学来的"——不是"这话被哪篇论文证过"。**不装客观，把主观的部分老实标出来。**
