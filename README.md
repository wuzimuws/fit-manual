# 高性价比新手小白健身指南

给刚开始想健身的新手小白：**不谈天赋，不谈具体训练动作，简单聊一聊一些对新手可能有用、可能无用的知识。**

作者练了一年，遇到一些伤痛，踩过许多坑，也看过一些书和论文。这本指南就当作自己一年来的小总结吧。

---

## 免责声明

**这本指南完全是我个人的经验**，是我根据自己的情况总结出来、供大家参考的内容，个人感受必然有错漏之处，**具体真伪、可信程度，还请大家自行甄别。**

它不能替代教练、医生和康复师，希望给新手提供一些思路。

**资料来源**：我看的书籍 + 论文，每条的「主观证据等级」和「来源」都由我自己主观填写。

---

## 怎么读

**不用从头读到尾。** 找你现在卡住的那件事，随意翻看。

**8 节**，可以按顺序读，也可以只读当前需要的：

| 节 | 什么时候看 |
|---|---|
| [前言 · 我练的第一年](前言.md) | **从这里开始。** 我是谁、踩过哪三个坑、为什么写这本 |
| [1. 心态](book/01-心态.md) | **先看这节。** 习惯怎么养成、为什么开始最难、去之前要克服什么、中断了怎么办 |
| [2. 训练](book/02-训练.md) | **先建立整体认识**（书 + 解剖软件）；热身、选循环、8–15 次做组、怎么加重 |
| [3. 易被忽略的](book/03-易被忽略.md) | **练过一阵再回来查**：背没感觉、抬手臂会卡、膝盖内扣——肩胛 · 髋 · 踝 |
| [4. 饮食](book/04-饮食.md) | 吃够、吃得干净、喝大水；三日配比表；控盐；每日食物清单；膳食纤维 |
| [5. 恢复](book/05-恢复.md) | 睡几点、什么时候不练、酸痛和疼痛怎么分 |
| [6. 补剂](book/06-补剂.md) | 只买这五个，别的都别买——排在吃够、睡够、练对之后 |
| [7. 伤痛与安全](book/07-伤痛与安全.md) | **先查维 D**、耳石症个案、不适怎么描述 |
| [8. 消费与消毒](book/08-消费与消毒.md) | 去不去健身房、怎么选、月卡不是年卡、怎么挑教练、装备用品 |
| [结语](结语.md) | 读完全书之后再看——从健体到修心 |
| [附录 · 参考书目](附录-参考书目.md) | 全书引用来源汇总：书籍 10 本 + 论文 15 篇 |

**三条线串全书**：

- **维生素 D**：06 补剂 → 07 先查维 D → 07 耳石症 → 07 骨折风险
- **解剖结构**：02 第 1 条（先建立地图）→ 03（易被忽略的）→ 07 第 4 条（把不适说清楚）
- **没有中断这回事**：01 第 10 条（断了两周怎么回来）→ 05 第 4 条（没睡好还练不练）→ 01 第 11 条（心情不好可以练）
